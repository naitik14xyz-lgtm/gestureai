🖐️ GestureAI — AI Based Hand Gesture Recognition System

GestureAI is a real-time, 100% in-browser computer vision web application that detects 21 3D hand landmarks directly from a webcam using MediaPipe HandLandmarker and classifies 11 distinct hand gestures using geometric joint-angle rules with temporal smoothing. Because all AI inference runs locally via WebAssembly, video frames never leave the user's device.

✨ Key Features & Touchless Applications

📊 Touchless Presentation Controller: Navigate slides, toggle speaker notes, control a presentation timer, and project a live laser pointer using hand gestures.

🎵 Gesture Media Player: Play/pause synthesized audio tracks, switch songs, adjust volume, and mute hands-free with a live audio visualizer (Web Audio API).

🏠 Smart Home IoT Panel: Simulate touchless control of room lights, ceiling fan speeds, air conditioning temperature, smart door locks, and an energy-saver all-off mode.

🗣️ Assistive Sign-to-Speech Communicator: Translate recognised hand gestures into customizable spoken phrases using the browser's Speech Synthesis API.

🎨 Air Canvas Studio: Draw and erase in mid-air using your index finger (or quick 2-finger erase), undo strokes, change ink colors, and export artwork as a PNG.

📐 Smart Inspector & Gesture Simulator: Inspect live finger joint angles, practice with a gesture speed trainer, trigger 2-step gesture combos, or test every application without a webcam using the built-in Gesture Simulator.

🛠️ Tech Stack

Frontend: HTML5, CSS3 (Custom Lime Green & Deep Purple Theme with Dark/Light mode), Vanilla JavaScript

AI & Computer Vision: MediaPipe Tasks Vision (HandLandmarker via WebAssembly/WebGL)

Browser APIs: MediaDevices (getUserMedia), HTML5 Canvas 2D, Web Audio API, Web Speech API
